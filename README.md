Unsupervised Learning Project: VAE for Music Clustering

In this project, I implemented an unsupervised learning pipeline inspired by Variational Autoencoders (VAE) for clustering music tracks. The goal was to extract latent representations from audio, lyrics and genre and perform clustering. I explored different VAE architectures, such as Basic VAE, Convolutional VAE and Condiitonal VAE, analyzed clustering results, and compared with baseline methods like K-Means, PCA.

From the original audio files, MFCC features and lyric embeddings are extracted to create a processed dataset suitable for variational representation learning. The resulting feature dataset is publicly available at https://drive.google.com/drive/folders/1J3F5L6XsmgVoyoJ6JdhMZfmwGDJ70QIM
